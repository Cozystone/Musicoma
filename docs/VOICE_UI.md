# 목소리로 만들기 (2026-10-15, 본인 목표: "음성만으로 AI 와 실시간 대화하며 피드백 → 만들기 → 피드백")

## 지금 되는 것 — 말 + 흥얼거림 한 번에
화면 🎤 버튼(누르고 말하고 다시 누름). 한 녹음에 지시와 소리가 섞여도 된다:
> "이 리듬으로 1분 20초 뒤에 네 번 반복해서 넣어줘 — 투두투두투두…"

`hum.understand(path, bpm, key)`:
1. 받아쓰기(faster-whisper)로 **말** 단어를 찾는다. 의성어(투두·둥·딩·츠…)는 말이 아니다.
2. **음악 구간** = 소리가 나는 곳 − 말한 단어 구간(받아쓰기는 흥얼거림을 자주 빼먹어서 소리 크기로 찾는다).
3. 음악 구간마다 `hum.listen` — 음절(소리 크기 골짜기로 나눔) → 음높이 → **선율 모양 그대로 곡 조성으로 통째로 이동** →
   박자 없이 부른 걸 곡의 8분 격자에 맞는 템포로 자동 맞춤. 비트박스는 킥·스네어·햇.
4. 말에서 배치 추정(`parse_place`: "1분 20초", "80초", "33마디", "네 번 반복"). 나머지 해석은 프로듀서 AI.
화면은 말까지 했으면 바로 프로듀서에게 보낸다(들은 말 + 들은 음 + 파일 경로 → `hum_place`).

검사(`works/tests/hum_check.py`): 합성 멜로디(음정 25~40센트 틀림) 6/6 · 합성 비트박스 8/8 · 본인 실녹음 '투두투두' 8음절 ·
말+흥얼거림 섞인 녹음에서 지시("1:20", 4번)와 8음 분리.

본인 실녹음(10-15, 4.2초): 처음 0.5초 숨소리(-58dB) 무시, 8음절 G#2 C#3 G3 G3 G3↘Eb3 G#3 D3 → D단조로 +2 이동
Bb2 D3 A3 A3 A3 F3 Bb3 E3(맞춤 88%), 녹음 템포 76.6 → 곡 92 BPM 의 8분 격자. 예전 방식은 숨소리를 음으로 잡고(C2·D2) 같은 음 음절을 한 음으로 뭉쳤다(G3 2박짜리 하나).

## 다음 단계(실시간 대화)
1. 지금: 누르고 말하기(push-to-talk) → 프로듀서가 실행 → 결과를 화면에서 재생.
2. AI 가 **말로 답하고** 바뀐 부분을 바로 들려주기(TTS + 해당 구간 재생) — 손 안 대고 한 바퀴.
3. 손 안 대기: 말 끝 감지(VAD)로 버튼 없이, 재생 중에도 끼어들기. 받아쓰기 스트리밍.
